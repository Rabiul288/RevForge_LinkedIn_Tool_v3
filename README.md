## Setup (optional)
Open the **Settings** tab to add your own Anthropic API key,
SMTP email, Slack webhook, or Zapier webhook.
All data is stored locally on your PC.

## Run from source
Python 3.10+ required. Download `_LinkedIn_Tool_v3.py` and run:
